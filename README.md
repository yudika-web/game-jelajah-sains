## Menjalankan

**Windows, tanpa mengetik perintah:** ekstrak ZIP, pasang [Node.js 24 LTS beserta npm](https://nodejs.org/) sekali, lalu klik ganda **SIAPKAN_ATAU_PERBARUI.bat**. Setelah muncul BERHASIL, buka **JALANKAN_JELAJAH_SAINS.bat**. Pada hari berikutnya cukup buka file Jalankan tersebut. Gunakan **DIAGNOSTIK_JELAJAH_SAINS.bat** bila ada masalah. [Panduan pertama kali, harian, pembaruan, LAN, dan progres](docs/windows-launcher.md).

Peluncur harian menyajikan **build produksi `dist`**, bukan dev server. Internet dan npm tidak diperlukan untuk bermain jika Node.js/build tersedia. Browser dibuka setelah server siap pada **http://localhost:5173**; biarkan jendela server terbuka, tekan **Ctrl+C** untuk menghentikan. Port tidak berganti otomatis dan aplikasi lain tidak dimatikan. **Jangan membuka index.html langsung.** Paket ini masih memerlukan Node.js, bukan EXE mandiri. BAT belum diuji langsung pada Windows.

Alamat/origin lama tetap perlu diperhatikan: `127.0.0.1`, `localhost`, port 4173, dan IP LAN memiliki penyimpanan browser berbeda. Ekspor di alamat lama lalu impor di alamat baru bila berpindah. IndexedDB tidak dihapus. Kandidat LAN tercetak pada server; akses dari HP/IFP membutuhkan jaringan yang sama dan belum dibuktikan dengan perangkat fisik.

Untuk pengembang atau sistem selain Windows (Node.js >=22.12.0, npm >=10):

```sh
npm ci
npm run dev       # Vite pengembangan, port 5173 tetap
npm run prepare:local # instalasi bila perlu + build dengan penggantian aman
npm start         # server statis produksi, port 5173 tetap
npm run diagnose:local
```

Hentikan dev server sebelum memakai server produksi pada port yang sama. Tidak memerlukan API key, akun, database server, atau aset CDN. Jika cache npm bawaan pada lingkungan cloud tidak dapat ditulis, gunakan `npm ci --cache /tmp/jelajah-npm`; persiapan otomatis memakai cache sementara yang dapat ditulis.

```sh
npm test          # aturan misi, cadangan, navigasi, karakter dan gerak
npm run test:launcher # server statis, port/identitas, persiapan dan rollback
npm run build     # TypeScript + bundle produksi di dist/
npm run preview   # pemeriksaan pengembang saja, port 4173
npm run test:e2e  # Chromium: regresi game + produksi/permainan/galeri
```

E2E menggunakan Chromium sistem di `/usr/bin/chromium`. Di komputer lain, atur `CHROMIUM_PATH` ke executable Chromium yang terpasang. Pengujian memakai SwiftShader agar WebGL dapat diperiksa tanpa GPU. Ini bukan pengukuran performa perangkat sekolah. Playwright menjalankan dev server sendiri bila port belum digunakan.

Saat berbicara/membaca/mengukur, panel ditempatkan di sisi layar lebar atau bagian bawah layar potret. Karakter tetap terlihat, dengan pose dan alat yang sesuai. Berjalan berhenti selama panel terbuka, tetapi animasi interaksi tetap berjalan; pengurangan gerakan menghentikan ayunan idle, kedipan, dan langkah dekoratif.

## Menuntaskan M16-E3

1. Masuk Rimba lewat gerbang Kota. Pilih **M16-E3** dan temui Pak Damar untuk menerima episode. Misi lama bukan prasyarat.
2. Baca dua kartu di **Buku tekanan padat** dan satu kartu **Kebutuhan penopang**. Di **Gaya alat**, periksa 400 N. Di **Ukur penopang**, ukur panjang/lebar A/B/C, lalu pilih variabel luas kontak.
3. Pasang penopang dari rak atau meja. Simpan prediksi, Letakkan beban, Amati bidang kontak, Catat hasil, lalu Angkat beban & siapkan ulang media. Urutan A/B/C bebas. Ketiganya memakai gaya tetap 400 N; tekanan yang dihitung adalah 10, 5 dan 2,5 kPa.
4. Coba tantangan pada **jalur maket**, bukan jalan manusia. Panjang penopang sejajar jalur. A muat tetapi melebihi 6 kPa; C tertahan pada gerbang 30 cm sehingga beban tidak menekan media; B muat dan memenuhi batas tekanan. Memilih B tanpa menjalankan serta mencatat uji belum cukup.
5. Pulihkan Maket, lalu sampaikan kesimpulan kepada Pak Damar. Refleksi opsional tidak dinilai melalui kata kunci. Hadiah pertama 50 XP sekali. Reset meminta konfirmasi dan hanya mengulang M16-E3.

Warna pada penopang memproyeksikan bidang kontak yang berada di bawahnya. Satu panah gaya berukuran tetap memperlihatkan gaya total yang sama. Penopang dan jalur diperbesar ×3, dengan rasio panjang/lebar tetap. Media memakai batas latihan, bukan hukum kedalaman ambles atau panduan keamanan tanah nyata. Membatalkan, menutup panel, berpindah wilayah atau reload memulihkan satu beban dan media tanpa hasil baru; bukti sah tetap tersimpan. Logistik air dan gerobak tidak menjadi sumber gaya atau barang percobaan ini.

## Menuntaskan M16-E2

1. Masuk Bengkel melalui gerbang Kota. Pilih **M16-E2**, temui Kak Bima dan terima episode. Misi lama bukan prasyarat.
2. Baca dua kartu di **Buku hidraulik** dan kartu **Catatan lift**. Dekati **Kebutuhan peti**, periksa berat 100 N dan target 5 cm, lalu pilih variabel luas piston keluaran.
3. Di Rak modul atau Lift hidraulik, pasang A/B/C hanya saat platform awal dan peti tersangga. Simpan prediksi, Jalankan uji awal, Amati kedua piston, Catat hasil, lalu Kembalikan platform. Ulangi ketiga modul.
4. Jalankan tantangan dengan batas gaya 50 N dan gerak masukan 12 cm. A tertahan; C hanya naik 3 cm; B mencapai 5 cm. Percobaan salah dapat dicatat dan diperbaiki. Memilih B tanpa mengangkat dan mencatat belum memenuhi tugas.
5. Pulihkan alat, lalu simpulkan bersama Kak Bima. Usaha ideal ketiga pengujian awal adalah 5 J; keuntungan gaya diimbangi gerak lebih panjang. Refleksi opsional tidak dinilai dengan kata kunci. Hadiah pertama 50 XP sekali.
6. Panel atau pengukuran yang ditutup sebelum Catat tidak menjadi bukti. **Pulihkan Alat** menjaga hasil sah. Reload menempatkan peti yang sama pada posisi aman. Reset M16-E2 meminta konfirmasi dan tidak menghapus misi lain atau riwayat hadiah.

Penampang piston 3D diperbesar ×12 agar terbaca; gerak vertikal tetap 1:1 dalam meter dunia. Diagram gerak pada panel diberi label pembesaran dan angka sebenarnya. Pengaturan kamera eksplorasi tetap setelah panel ditutup. Perubahan tab/fokus menghentikan animasi; tidak ada batas waktu, tenaga fisik atau ketukan cepat.

## Menuntaskan M16-E1

1. Di Pesisir, pilih M16-E1, temui Kak Lestari dan terima episode. Baca Buku tekanan dan Rencana tekanan. Di Sensor tekanan, Ambil lalu Periksa fungsi.
2. Dekati **Pos kendali ROV** dan Kendalikan. Karakter tetap di pos; kamera mengikuti robot. Di dok 0 m pilih Stabilkan → Jalankan pembacaan → Catat. Ini pemeriksaan nol relatif, bukan tekanan total nol.
3. Pilih variabel **kedalaman sensor**. Praktikkan gerak horizontal, perubahan kedalaman, stabilisasi dan Kembali ke Dok. Tujuan otomatis juga dapat dipakai untuk tutorial. Kendalikan kembali setelah tutorial.

## Penyimpanan

Progres disimpan otomatis ke **IndexedDB `jelajah-sains`, skema 1**, object store `saves`. Rekaman `M01` lama dipertahankan; rekaman `M14`, `W03-LOG01`, `S13`, `S14`, `S15`, `M17-E1`, `M17-E2`, `M17-E3`, `S16`, `M16-E1`, `M16-E2`, `M16-E3`, `M16-E4`, `M13`, `M07`, `M02`, dan `world` menyimpan progres misi serta wilayah/misi aktif. Ketujuh belas misi/episode ditulis dalam satu transaksi. Muat ulang mempertahankan hari, petak, air, data, dan hadiah; pemain ditempatkan pada pos aman wilayah terakhir. Preferensi kamera/kontrol tetap terpisah.

**Pengaturan → Ekspor cadangan / Impor cadangan** menyediakan format cadangan **versi 18** berisi tujuh belas episode/misi, wilayah, dan penampilan pribadi. Versi **1–17** tetap didukung dan mempertahankan penampilan yang tidak tercakup. Versi cadangan berbeda dari versi skema IndexedDB. Versi **16** memulihkan sampai M07; seluruh versi **1–16** mempertahankan M02 yang tidak tercakup. Cadangan M01 **versi 1** tetap diterima: impor menjelaskan bahwa hanya M01 dipulihkan dan M14/Rimba/S13 yang ada dipertahankan. Cadangan gabungan **versi 2** memulihkan M01/M14 dan wilayah, sambil mempertahankan Rimba/S13. Cadangan **versi 3** memulihkan tiga misi lama sambil mempertahankan S13/S14/S15. Versi **4** memulihkan sampai S13, versi **5** sampai S14; S15 yang tidak dicakup tetap ada. Cadangan **versi 6** memulihkan enam misi lama sambil mempertahankan M17-E1. Versi **7** memulihkan sampai M17-E1; versi **8** sampai M17-E2, sambil mempertahankan M17-E3 yang tidak tercakup. Versi **9** memulihkan sampai M17-E3 dan mempertahankan S16. Versi **12** memulihkan sampai M16-E2. Versi **13** memulihkan sampai M16-E3. Versi **15** memulihkan sampai M13; seluruh versi **1–15** mempertahankan M07 yang tidak tercakup. Versi **14** memulihkan sampai M16-E4; seluruh versi **1–14** mempertahankan M13 yang tidak tercakup. Seluruh versi **1–13** mempertahankan M16-E4 yang tidak tercakup. ## Batas prototipe

Belum mencakup wilayah di luar delapan wilayah ini, melompat atau menyelam sebagai manusia, berenang di luar kolam, kendaraan selain gerobak/perahu/ROV latihan, audio, kustomisasi avatar selain siswa/siswi, mode guru/dasbor, pengiriman nilai, atau multiplayer. Browser tanpa WebGL 2 mendapat materi 2D dan petunjuk pemulihan; itu bukan petualangan 3D. Ukuran tombol, keterbacaan kelas, FPS, dan akses LAN perlu diperiksa pada HP serta panel IFP fisik sebelum penggunaan kelas. Tidak ada data siswa yang dikirim ke server.

Perjalanan W07: **Kota → Bengkel → Terminal kunjungan Geopark**. Pilih M13 dari Kota bila ingin petunjuk perjalanan; pilihan ini tetap aktif saat melewati Bengkel. Pulang melalui **Terminal kembali ke Bengkel**; seluruh misi lama tetap dapat dilanjutkan. Pengaturan menyediakan **Ulangi M13 Geopark** dengan konfirmasi. Peta dan kartu misi mendukung navigasi sentuh. Penggunaan pertama Windows tetap melalui **SIAPKAN_ATAU_PERBARUI.bat**, lalu **JALANKAN_JELAJAH_SAINS.bat**; Node.js masih diperlukan.

Perjalanan W08: **Kota → Observatorium / Antariksa → Masuk Simulasi Antariksa**. Kunjungi Bu Nara, buku dan catatan di dua lokasi, lalu tiga stasiun. Kembali melalui terminal Kota. **Jalankan/Jeda** dan **Langkah** tersedia; pengamatan belum menjadi bukti sebelum **Amati → Catat**. Revolusi membutuhkan gerak penuh, bukan reset posisi. Fase memakai kamera instrumen yang sama; preferensi kamera eksplorasi dipertahankan. S22/S23/S24 tidak otomatis selesai. Pengaturan menyediakan reset M07 dengan konfirmasi dan hadiah pertama tetap tersimpan.

Perjalanan M02: pilih **M02 Persediaan Es Pasar → Peta → Pak Wira**. Buku IPA pasar dan Catatan pasar berada di lokasi berbeda. Meja Es & penguapan, Massa & volume, Uji wadah es, serta Kemas kiriman dapat dicapai melalui Peta atau berjalan biasa. **Mode langkah** dipilih sebelum Jalankan; pengurangan gerakan memakai langkah tetap. Hasil baru tersimpan setelah Amati, Baca neraca (bila diperlukan), dan Catat. Sampel latihan tidak menjadi paket kiriman.

Paket **M02-ICE-001** dibawa pada tangan. Antar ke **Bu Nara**, Periksa hasil interval distribusi tetap **20 menit virtual**, lalu Serahkan. Waktu berjalan, membaca, jeda dan waktu offline tidak mengurangi es. Ambang **750 g** berlaku pada es padat, bukan total es + air. Paket yang belum diterima dipulihkan ke kios saat reload, Kembali ke Pos, perpindahan wilayah, atau Pulihkan Paket di Tas; hasil uji tetap ada. Paket yang sudah diterima tetap pada penerima. Kembali ke Pak Wira untuk kesimpulan. Reset M02 meminta konfirmasi dan mempertahankan receipt hadiah pertama; S02/M03/S14 serta status M16/M17 tetap terpisah.
